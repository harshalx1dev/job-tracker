If you have not read the Trackr playbook in this session, call get_playbook first. Then run the Refresh command: call get_profile, list_jobs, list_answers and list_resumes again, because I may have changed my profile, preferences, answers, resumes or jobs in Trackr since you last loaded them. Compare with what you knew earlier and tell me briefly what changed (new or edited answers, preferences, resume names, jobs). Keep using the same resume unless it no longer exists. Do not search or apply.
